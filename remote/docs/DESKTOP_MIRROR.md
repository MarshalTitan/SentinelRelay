# Desktop mirror and rescue controls — 0.3.0 candidate

The app mirrors the primary Windows monitor, including the desktop, other ordinary apps, XIVLauncher, login/title/character-selection screens and the game. The user operates these screens manually. Once the selected character is verified by Relay, the same view can show the existing rescue gamepad. It is intended for occasional recovery and menu/target selection; this preview is not a high-frame-rate game streaming product.

1. Exit Sentinel Remote from its tray and install Windows **0.3.0** over the existing PC app. Keep the current Relay DLL and installed controller driver.
2. Connect securely. Select the intended paired control phone, then click **Allow selected phone desktop**. This explicitly grants primary-desktop viewing and touch/keyboard control of ordinary apps/files. It clears on host restart or **Stop desktop access**. Existing pairing persists; **Revoke** and **Disable all remote access** also stop desktop access.
3. Install Android Preview **0.3.0**. Preview signing is temporary; Android may require uninstalling only **Sentinel Remote Preview** and re-pairing. The original status/rescue app can remain installed.
4. Open **Desktop** on the phone while FFXIV is closed. Pinch to zoom/pan. Tap selects/clicks, double-tap opens, long-press right-clicks. Use **Start** to open the Windows menu or open XIVLauncher from an icon; any ordinary app/file can be opened through the visible desktop.
5. Tap a launcher text field, use the keyboard icon, enter any required login/OTP text, then **Send once**. Use Tab/Enter or tap Log In. Sentinel does not read saved launcher credentials or store the text. The phone typing dialog clears on cancellation/background/disposal. Handle login and select the intended character manually.
6. After Relay shows the enrolled character connected, use the gamepad icon in Desktop and **Start gamepad**. Prepare and allow that phone's gamepad once in the PC app as before. The screen stays visible above the controls in portrait or beside them in landscape. The gamepad remains limited to exactly one verified FFXIV process, identity/epoch and local opt-ins. View loss releases it; reacquisition is explicit.
7. **Stop desktop**/Back closes the phone view. The PC footer/tray shows when desktop access is active. **Stop desktop access** on the PC revokes that local permission. **Disable all remote access** remains the always-reachable emergency control.

Keep Windows awake and unlocked. The monitor may be off, but actual capture/rendering with the user's GPU/display/power setup must be tested. A truly powered-off/disconnected display can behave differently from a display in standby; no virtual-display driver is installed. This preview shares the primary monitor only. Restore FFXIV on the desktop when you want to see its window; a minimized game still accepts the separately approved gamepad with FFXIV's inactive-client gamepad setting enabled, while the desktop naturally shows whatever is visible there.

## Bounds and field gate

Private Tailscale Serve and independent application pairing remain required. No public listener, port forwarding or Funnel. Frames are in-memory JPEG up to 1280×720/320 KiB at at most three per second; one view per host, strict 4 KiB input messages, 12 requests/sec maximum, increasing socket sequence, recent unguessable frame ID, normalized coordinates and complete down/up input batches. No image/text/request-body logging, disk recording, clipboard export, remote path/arguments or automatic action retry.

Native Windows capture and SendInput cannot certify themselves through protocol fakes. Verify on the real PC: correct primary desktop; accurate clicks at current DPI; double-tap opening an app; typing into a harmless field; actual XIVLauncher login and intended character selection; game view plus movement/targets/menu buttons; Stop/background/connection loss/revoke/disable; no held inputs; stale-frame rejection; monitor standby/off. Existing native-controller field gates remain open. Protected/elevated/lock screens are outside this ordinary-user preview. Confirmed automatic logout is still unimplemented; manual menu navigation is available through the desktop/gamepad.
